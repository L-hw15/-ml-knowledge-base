```python
"""
K-Means聚类完整示例
数据：scikit-learn内置数据集（模拟）
"""

import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_blobs
from sklearn.metrics import silhouette_score

# 1. 生成模拟数据（或替换为真实数据）
X, y_true = make_blobs(
    n_samples=300,
    centers=3,
    cluster_std=1.0,
    random_state=42
)

# 2. 数据标准化（K-Means对尺度敏感）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. 确定最优K值（肘部法则）
inertias = []
silhouettes = []
K_range = range(2, 10)

for k in K_range:
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    kmeans.fit(X_scaled)
    inertias.append(kmeans.inertia_)
    silhouettes.append(silhouette_score(X_scaled, kmeans.labels_))

# 4. 绘制肘部法则图和轮廓系数图
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].plot(K_range, inertias, 'bo-')
axes[0].set_xlabel('Number of clusters (K)')
axes[0].set_ylabel('Inertia')
axes[0].set_title('Elbow Method')

axes[1].plot(K_range, silhouettes, 'ro-')
axes[1].set_xlabel('Number of clusters (K)')
axes[1].set_ylabel('Silhouette Score')
axes[1].set_title('Silhouette Method')

plt.tight_layout()
plt.savefig('kmeans_evaluation.png', dpi=150)

# 5. 使用K=3进行聚类（示例）
best_k = 3
kmeans = KMeans(n_clusters=best_k, random_state=42, n_init=10)
labels = kmeans.fit_predict(X_scaled)

# 6. 可视化结果
plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis', s=50, alpha=0.7)
plt.scatter(
    kmeans.cluster_centers_[:, 0],
    kmeans.cluster_centers_[:, 1],
    c='red', marker='X', s=200, edgecolors='black'
)
plt.title(f'K-Means Clustering (K={best_k})')
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.savefig('kmeans_result.png', dpi=150)

# 7. 输出评估指标
sil_score = silhouette_score(X_scaled, labels)
print(f"轮廓系数 (Silhouette Score): {sil_score:.4f}")
print(f"各簇样本数: {np.bincount(labels)}")
```

**模板填充**：
- 槽位填充：ml:KMeans（事实类-实体类-Model）

**覆盖率**：0.95 → 直接出稿

### 第④段 编排产物

```
K-Means聚类算法原理

【基本原理】
K-Means是一种聚类算法，将数据划分为K个簇，使簇内方差最小化。
算法通过迭代方式将每个数据点分配给最近的簇心，然后更新簇心位置，
直到簇心不再发生变化或达到最大迭代次数。

【数学表示】
目标函数：J = Σ||x_i - μ_{c_i}||²
其中 x_i 为数据点，μ_{c_i} 为数据点所属簇的簇心

【算法步骤】
1. 初始化：随机选择K个数据点作为初始簇心
2. 分配：将每个数据点分配给距离最近的簇心
3. 更新：重新计算每个簇的均值作为新簇心
4. 重复步骤2-3，直到收敛或达到最大迭代次数

【优缺点】
- 优点：简单高效，适合大规模数据；收敛速度快
- 缺点：对初始簇心敏感；只能发现球形簇；对异常值敏感

【适用场景】
- 客户细分
- 图像压缩
- 文档聚类
- 异常检测

【 sklearn API】
from sklearn.cluster import KMeans
model = KMeans(n_clusters=3, random_state=42)
labels = model.fit_predict(X)
```
